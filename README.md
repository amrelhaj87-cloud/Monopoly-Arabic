## 🌟 نبذة عن المشروع

**أملاك وعقارات (Amlak & Real Estate)** هي نسخة ويب متكاملة وعصرية من لعبة الصفقات والتجارة العقارية، تم تعريبها وتصميمها بهوية عربية فاخرة وبأحدث تقنيات الويب التفاعلية.

تتيح اللعبة التنافس بين **1 إلى 6 لاعبين** سواء في نمط اللعب الفردي ضد روبوتات ذكاء اصطناعي ذكية بأسماء وشخصيات عربية، أو اللعب الجماعي أونلاين عبر إنشاء غرف خاصة ومشاركة كود الغرفة المباشر مع الأصدقاء.

## ✨ أبرز المميزات

### 1. 👥 أنماط لعب مرنة (1 إلى 6 لاعبين)
* **اللعب الفردي (ضد الذكاء الاصطناعي):** نافس حتى 5 روبوتات ذكية بمستويات صعوبة متنوعة (سهل 🟢، متوسط 🟡، محترف الهامور 🔴) وشخصيات عربية مميزة (أبو فهد، شهاب، ليلى، طارق، سارة، سلطان).
* **الغرف الخاصة (Multiplayer Rooms):** أنشئ غرفة برمز سداسي فريد ورابط دعوة مباشر، مع ردهة انتظار (Lobby)، شات ومحادثة حية، وفحص جاهزية اللاعبين.
* **النمط السريع (Quick Mode):** خيار لتوزيع عقارين عشوائيين في بداية المباراة لتسريع وتيرة اللعب.

### 2. 🔐 نظام الهوية والمصادقة
* **دخول فوري كزائر (Guest Mode):** اختر اسمك وشخصيتك (الأفاتار) ورمزك المفضل وابدأ اللعب مباشرة.
* **تسجيل الدخول عبر Google / Gmail والبريد الإلكتروني:** عبر Firebase Auth لحفظ سجل المباريات والإحصائيات وأعلى ثروة مسجلة.
* **مرونة الاتصال بـ Firebase:** يعمل النظام مباشرة أوفلاين/محلياً مع إمكانية إدخال مفاتيح مشروع Firebase الخاص بك من واجهة الإعدادات.

### 3. 🎲 قواعد وآليات اللعبة الكاملة
* **رقعة كاملة (40 خانة كلاسيكية):** تشمل 22 مدينة وعاصمة عربية، 4 محطات قطار سريعة، شركتي خدمات عامة (الكهرباء والمياه)، والزوايا الخاصة والضرائب.
* **بناء المنازل والفنادق 🏨:** ابنِ حتى 4 منازل ثم فندقاً فاخراً على المجموعات اللونية الكاملة لمضاعفة الإيجارات.
* **المزادات العلنية المباشرة (Live Auctions) 🔨:** مزايدة حية بمؤقت تنازلي في حال رفض أي لاعب شراء العقار.
* **نظام التداول والمقايضة 🤝:** واجهة متقدمة لتبادل العقارات والأموال بين اللاعبين والروبوتات.
* **الرهن وفك الرهن 🔒:** رهن العقارات للحصول على سيولة وفك الرهن بفائدة 10%.
* **بطاقات صندوق الحظ وفرصة (32 بطاقة) 🎴:** مواقف عربية واقعية ومكافآت وغرامات حماسية.
* **نظام السجن والإفلاس:** كفالة السجن، بطاقة العفو الملكي، رميات الدبل، وتصفية الديون.

### 4. 🎨 تصميم فاخر وتجربة مستخدم استثنائية
* **Dark Gold / Royal Emerald Theme:** تصميم زجاجي فاخر (Glassmorphism) مع خطوط عربية مميزة (Cairo, Tajawal, Outfit).
* **منظور ثلاثي الأبعاد تفاعلي (3D / 2D Toggle):** إمكانية إمالة الرقعة بمنظور ثلاثي الأبعاد أو العرض المسطح.
* **محرك صوتي متكامل (Web Audio API):** أصوات نقود (Cha-Ching)، رمي النرد، بناء البيوت، السجن، ونغمات الفوز مع احتفالات الكونفيتي.

## 🛠️ التقنيات المستخدمة

* **الواجهة الأمامية:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/)
* **التصميم والأنماط:** Modern Vanilla CSS + CSS Variables + Glassmorphism (دعم RTL أصيل)
* **الأيقونات:** [Lucide React](https://lucide.dev/)
* **المؤثرات الصوتية:** Web Audio API Custom Synthesizer (بدون ملفات صوتية خارجية ثقيلة)
* **المزامنة السحابية:** [Firebase](https://firebase.google.com/) (Auth & Firestore) + BroadcastChannel للشبكة المحلية
* **المؤثرات الاحتفالية:** [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)

## 🚀 طريقة التشغيل والتثبيت

### المتطلبات الأساسية
* [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
* npm أو yarn أو pnpm

### خطوات التثبيت والتشغيل

1. **استنساخ المستودع (Clone):**
```bash
git clone https://github.com/amrelhaj87-cloud/amlak-aqaarat.git
cd amlak-aqaarat
```

2. **تثبيت الحزم والاعتماديات:**
```bash
npm install
```

3. **تشغيل خادم التطوير المحلي:**
```bash
npm run dev
```

4. افتح المتصفح على الرابط: **`http://localhost:3000/`**

### بناء نسخة الإنتاج (Production Build)
```bash
npm run build
```
